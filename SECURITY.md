# Security Policy

## Supported version

V0.1.x is an alpha research/engineering release.

## Reporting vulnerabilities

Do not publish private keys, recipient mappings, or exploit details containing real confidential assets in a public issue. Provide a minimal reproducible report with synthetic or redacted data.

## Security boundaries

AI-IP Shield is a defensive evidence system. It does not promise unremovable watermarks, DRM enforcement, legal ownership determinations, or technical prevention of AI training.

Private signing keys must never be committed to the repository. Use opaque fingerprint IDs; keep personal data in controlled registries.
